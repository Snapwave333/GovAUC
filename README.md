## 🎪 The Opportunity

> **Did you know?** Government agencies are *legally required* to auction off seized and surplus property. These auctions happen on **1000+ obscure, poorly-designed websites** that most people never find.

**GovAUC** is your unfair advantage. It's an AI-powered bot that:

- 🕷️ **Scrapes** thousands of government auction sites automatically
- 🧠 **Analyzes** messy government data with AI-powered parsing
- 💰 **Estimates** true market values using KBB, eBay & more
- 🎯 **Snipes** auctions in the final seconds to win deals
- 📊 **Delivers** high-ROI opportunities on a silver platter

## 🛠️ Installation

### Prerequisites

- Python 3.9 or higher
- pip package manager
- Git

### Quick Install

```bash
# Clone the repository
git clone https://github.com/yourusername/GovAUC.git
cd GovAUC

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install GovAUC
pip install -e .

# Or with development dependencies
pip install -e ".[dev]"
```

## 🚀 Quick Start

### 1️⃣ Initialize

```bash
govauc init
```
*Creates config, database, and adds default auction sites*

### 2️⃣ Scrape Auctions

```bash
govauc scrape --all-sites
```
*Fetches listings from all configured government auction sites*

### 3️⃣ Find Gems

```bash
govauc gems
```
*Displays high-opportunity listings (score ≥ 0.8)*

### 4️⃣ View Dashboard

```bash
govauc dashboard
```
*Shows real-time statistics and top opportunities*

<br/>

## 📋 All Commands

| Command | Description | Example |
|---------|-------------|---------|
| `govauc init` | Initialize configuration | `govauc init` |
| `govauc dashboard` | View statistics dashboard | `govauc dashboard` |
| `govauc scrape` | Scrape auction sites | `govauc scrape --all-sites` |
| `govauc gems` | Find gem opportunities | `govauc gems --min-score 0.9` |
| `govauc browse` | Browse by category | `govauc browse vehicle` |
| `govauc search` | Search listings | `govauc search "Ford F-150"` |
| `govauc analyze` | Run full analysis | `govauc analyze` |
| `govauc report` | Generate daily report | `govauc report` |
| `govauc add-site` | Add auction site | `govauc add-site "Police" "url"` |
| `govauc sites` | List configured sites | `govauc sites` |
| `govauc snipe` | Start auto-sniping | `govauc snipe --dry-run` |

## ⚙️ Configuration

```bash
cp config/config.example.json config/config.json
```

### Key Settings

```json
{
  "analysis": {
    "min_profit_threshold": 100,      // Minimum $ profit
    "min_roi_percentage": 50,         // Minimum ROI %
    "gem_score_threshold": 0.8        // Gem detection threshold
  },
  "sniping": {
    "enabled": false,                  // Enable live bidding
    "default_snipe_seconds": 30        // Seconds before end
  },
  "budget": {
    "total_budget": 10000.0,          // Total sniping budget
    "max_per_item": 1000.0            // Max per item
  }
}
```

## ⚠️ Automated Sniping

> **⚡ WARNING: Live sniping places REAL bids with REAL money.**

### Dry Run (Recommended First)

```bash
govauc snipe --dry-run --budget 5000
```

### Live Sniping

```bash
govauc snipe --budget 10000 --max-per-item 500
```

**How It Works:**
1. 🔍 Identifies gem opportunities
2. 📊 Calculates optimal bid amounts
3. ⏰ Schedules snipes based on end times
4. ⚡ Places bids 10-30 seconds before end
5. 🔄 Auto-counters if outbid (optional)
